RSVP Rules & Guest List Guide

Guest Types

Single 1 person. No party section shown on the RSVP form. Use for individual invitees.
Couple 2 people (lead + spouse/partner). Shows spouse name field. Use for married couples, engaged couples, or partners living together.
Family 2–10 people. Shows family member fields. Use for households with children or extended family.

How Invite Links Work

With id The RSVP is linked to the existing guest record. When they submit, their attendance status updates automatically in this admin panel. No duplicate records are created.
Without id The RSVP form works but creates a NEW guest record on submit. Use for walk-ins or unregistered guests. Phone is required in this case.
Pre-fill URL can also carry name, spouse, type, max, due, and msg to personalise the greeting and pre-fill fields.

Best Practices

  1. Always create guests here first, then use the WhatsApp button to send their personalised link. This ensures the id parameter is in the URL.
  2. Set max_party correctly: 1 for single, 2 for couple, the actual headcount for family.
  3. Set a deadline (default is June 17, 2026 — 3 days before the event).
  4. Check the Not Responded filter regularly to see who hasn't replied and follow up.
  5. "Ask Again Later" submits immediately with no party details required — the guest just wants a reminder closer to the date.
  6. Messages from guests go to the Messages inbox, separate from the RSVP data.

Common Pitfalls to Avoid

  • Don't send an invite link without the id — guests can still RSVP but it creates a new, unlinked record instead of updating theirs.
  • Don't delete a guest who has already RSVP'd — you'll lose their attendance response.
  • Don't edit a guest's name or ID after sending the link — the old link becomes stale. If you must edit, send the new link.
  • Don't send links manually via SMS — always use the WhatsApp button so the correct personalised message + link is sent.
